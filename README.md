# 采气工中级 理论刷题

移动端刷题 PWA 应用，涵盖采气工职业技能鉴定中级理论题库（913 题）。

## 使用方法

1. 浏览器打开本页面
2. iPhone: Safari → 分享 → 添加到主屏幕
3. Android: Chrome → 菜单 → 添加到主屏幕
4. 安装后就像 App，支持离线使用

## 功能

- 📝 自由练习：随机刷题，即时反馈
- 📋 模拟考试：自定义题量/时长，单选+判断混合出题
- 📂 知识点刷题：按章节专项练习
- 📌 错题集：自动收录，支持 AI 解析（DeepSeek）
- 📊 学习统计：正确率、各章节掌握度
